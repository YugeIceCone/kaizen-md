## How this file is built

The `render_checklist` merge action (or `kaizen-plan-checklist render` standalone) walks:

1. `chunks/*.yaml::tasks[]` for STATIC structure (item IDs + descriptions)
2. `ledger/MASTER.jsonl` for LIVE status (last-row-per-(chunk_id, item_id) wins)
3. Merges into this markdown render

Pseudo-code:

```python
plan      = yaml.safe_load(open("plan.yaml"))
chunks    = [yaml.safe_load(open(p)) for p in sorted(Path("chunks").glob("*.yaml"))]
ledger    = [json.loads(l) for l in open(plan["ledger_dir"] + "MASTER.jsonl") if l.strip()]
latest    = {(r["chunk_id"], r["item_id"]): r for r in sorted(ledger, key=lambda r: r["ts"])}
# (later rows overwrite earlier — last-write-wins)
```
